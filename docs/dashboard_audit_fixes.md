# 2026-10-08 대시보드 점검 후속 보완

## 가격 재조회

- `미완료 가격 재조회`는 failed뿐 아니라 stale, missing, missing_api_key를 포함한다.
- 사용자 재시도는 가격 캐시를 우회한다. 24초 예산과 공급원 호출 간격은 유지한다.
- 일부 종목을 조회해도 전체 보유종목 상태 목록을 시장/티커 키로 병합한다.
- 성공 종목 상태를 지우지 않고 남은 이전값/실패/미조회 개수를 계속 표시한다.

## BRK.B

- 사용자 티커 및 보유 데이터는 변경하지 않는다.
- Yahoo 현재가, 분봉, 차트분석 일봉 요청에서 미국 A/B 클래스 표기를 하이픈으로 변환한다.
- `BRK.B` -> `BRK-B`, `BRK.A` -> `BRK-A`. `.KS`, `.KQ`, `.L` 거래소 접미사는 유지한다.
- 공급원 응답의 티커는 원래 보유 티커로 돌려주어 가격 병합 키가 바뀌지 않게 한다.
- KIS 실패 시 기존 Yahoo fallback이 동작하며 KIS 종목코드를 추측해 바꾸지 않는다.

## 참고 Beta

- 기존 문제: 여러 날짜에 걸친 포트폴리오 수익률을 종료일 하루의 벤치마크 수익률과 비교했다.
- 수정: 실제 기록과 벤치마크가 모두 있는 시작/종료일을 먼저 맞춘 후 양쪽의 구간 수익률을 계산한다. 결측값은 보간하지 않는다.
- 저장 기록은 시간순으로 정렬한 뒤 KST 날짜별 마지막 기록을 사용한다.
- 입금, 출금, 초기 현금, 수동 현금 조정이 포함된 구간은 제외한다. 날짜만 있고 장중 흐름 시각이 없으므로 양쪽 경계일도 보수적으로 제외한다.
- 현재 원장 및 과거 snapshot backup 원장을 확인한다. 거래 정산/환전/배당은 외부 자금 유입으로 오인하지 않는다.
- 유효 구간이 20개 미만이면 산출하지 않는다. KRW 기준에서 환율 조회 실패 시 현지통화로 몰래 바꾸지 않는다.
- 과거 보유현황 재구성은 수량 변경을 외부 자금과 분리할 근거가 부족하므로 Beta 대체 자료로 자동 사용하지 않는다.
- 구간 길이와 저장 시각이 불규칙하므로 이름은 `참고 Beta`다. 정식 일간 종가 Beta/TWR가 아니다. 미기록 입출금이나 수량 편집은 보정할 수 없다.
- MDD는 기존 총자산 낙폭을 유지하되 입출금 조정 투자수익률 낙폭이 아님을 표시한다.

## 네이티브 테마와 헤더

- CSS만으로는 Streamlit Glide 캔버스의 픽셀 색이 바뀌지 않는다.
- `app/ui/native_theme.py`는 고정된 Streamlit 1.50 frontend의 `SET_CUSTOM_THEME_CONFIG` host 메시지로 해당 브라우저의 네이티브 테마를 맞춘다. 모든 색은 기존 토큰에서 가져온다.
- 서버 전역 테마, 사용자 데이터, 인증, 위젯 key, 선택 탭을 변경하지 않는다. 보안 origin allowlist도 앱에서는 변경하지 않는다.
- 배포 대상 `*.streamlit.app`은 Streamlit 기본 신뢰 origin이다. 일반 localhost 실행에서는 이 host 메시지가 거절될 수 있다. 로컬 시각 QA는 신뢰된 loopback만 추가하는 합성 데이터 전용 `python tests/browser/serve_fixture.py 8517`을 사용한다. 이 QA 런처를 운영 앱으로 배포하지 않는다.
- 이 브리지는 공개 Python 테마 변경 API가 아니라 버전 의존 frontend 프로토콜이다. Streamlit 업그레이드 시 browser smoke의 실제 native canvas 테마 검사를 반드시 통과시킨다.
- 갱신 버튼 아래에 갱신 시각을 배치하여 768px에서 가로 겹침을 제거한다.

## 차트 자동 이어 조회

- 차트 탭에서 최초 조회/수동 재조회 후 예산 때문에 남은 PENDING 종목만 3초 간격의 fragment로 이어서 처리한다.
- 한 묶음의 예산 24초, 단일 종목 캐시 30분은 유지한다. 공급원 단일 요청이 예산을 넘기는 경우 강제 취소하지는 않는다.
- 실제 FAILED/ERROR와 데이터 부족은 자동 무한 재시도하지 않는다. 이전 정상값은 유지한다.
- 대기 수가 줄지 않거나 배치 수가 종목 수에 도달하면 중단한다. 수동 중지 버튼을 제공한다.
- 완료 후 타이머를 해제하며 탭을 벗어난 상태에서 지속 조회하지 않는다. 서버가 브라우저 없이 계속 실행하는 백그라운드 작업이 아니다.

## 검증 범위

- 로컬 회귀 테스트와 합성 계정 브라우저 확인. 운영 거래/현금 원장 및 DB/RLS 변경 없음.
- 운영 API 복구, 실제 48종목 자동 진행, Android WebView 네이티브 테마는 배포 후 확인해야 한다.
